You are an expert Rust and Tauri v2 developer. Build a complete, production-ready LocalSend clone desktop application called "SwiftShare" with ALL features listed below. Every file must be complete, compilable, and production-ready.
---
PROJECT OVERVIEW
A fast, lightweight, cross-platform file sharing desktop app over local WiFi network. No internet required. No server required. Supports Windows, macOS, Linux.
---
TECH STACK
Frontend: React 18 + TypeScript + Tailwind CSS + Framer Motion

State: Zustand

Icons: Lucide React

i18n: i18next (Bangla + English)

Backend: Rust + Tauri v2

Async: Tokio

HTTP Server: Axum

HTTP Client: Reqwest

mDNS: mdns-sd

TLS: Rustls + rcgen

Storage: Sled (embedded DB for history + favorites)

Serialization: Serde + Serde_json

Testing: Rust test framework + Vitest + React Testing Library

discovery.rs
Register mDNS service "swiftshare.tcp.local." on startup

Include device name, port, device_type in TXT records

Continuously scan for peers — update every 5 seconds

Track last_seen timestamp per device

Remove devices not seen for 30 seconds

Emit Tauri event "devices-updated" with full device list on any change

Handle network changes (WiFi switch) by restarting mDNS

server.rs (Axum)
Endpoints:
GET /api/v1/info → return DeviceInfo JSON

POST /api/v1/prepare-upload → accept FileMetadata[], return session_id + token

POST /api/v1/upload/{sessionId}/{fileId} → receive file stream, save to disk

POST /api/v1/clipboard → receive ClipboardPayload

DELETE /api/v1/cancel/{sessionId} → cancel ongoing transfer

Behavior:
If quick_save=false: emit "incoming-request" Tauri event and WAIT for frontend to accept/reject (timeout 60s, default reject)

If quick_save=true: immediately accept and save

After each file saved: add to history via history.rs

Emit "transfer-progress" events during upload

Emit "transfer-complete" or "transfer-failed" on finish

sender.rs
Connect to target device HTTPS endpoint

Call /api/v1/prepare-upload with all file metadata

Wait for acceptance (poll or wait for response)

For each file: stream bytes in 64KB chunks

Track bytes sent → calculate speed + ETA → emit "transfer-progress" Tauri event

After all files: verify SHA256 of each file

Emit "transfer-complete" on success

Handle cancellation via AtomicBool cancel flag

clipboard.rs
send_clipboard(target: DeviceInfo, text: String) → POST to /api/v1/clipboard

On receive (server side): emit "clipboard-received" Tauri event with text + sender info

readsystemclipboard() → use arboard crate to read OS clipboard

writesystemclipboard(text: String) → write to OS clipboard

history.rs
Use Sled embedded database

savehistoryentry(entry: HistoryEntry)

get_history(filter: HistoryFilter) → Vec

clear_history()

delete_entry(id: String)

favorites.rs
Use Sled embedded database

add_favorite(device: DeviceInfo)

removefavorite(deviceid: String)

get_favorites() → Vec

isfavorite(deviceid: String) → bool

settings.rs
Load settings from app config directory (JSON file)

save_settings(settings: AppSettings)

get_settings() → AppSettings

Default settings on first run

Watch for settings changes and apply immediately (port change = restart server)

crypto.rs
Generate self-signed TLS cert on first run using rcgen

Save to app data dir

Load existing cert on subsequent runs

Return (certpem, keypem) for use in Axum TLS config
